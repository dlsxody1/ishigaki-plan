# 🏢 MetaDX 기업 홈페이지 — Core Web Vitals 개선

🧭 **바로가기** — [[index\|🏠 홈]] · [[index\|🧑‍💻 이력서 홈]]

**소속**: 주식회사 메타디엑스 (MetaDx Inc.) · **기간**: 2025.08 ~ 2026.05 · **역할**: 프론트엔드 개발

**Stack**: React 19, TanStack Router, Tailwind CSS v4, sharp, prerender(SSG), AWS S3

---

## 개요

회사 대외 홈페이지의 로딩 성능과 검색 노출을 개선하는 작업이었습니다. 사용자가 처음 페이지를 여는 순간의 체감 속도, 그리고 검색엔진이 콘텐츠를 제대로 읽어가는지가 핵심 지표였습니다.

## 🖼️ 이미지 로딩 지연 해결

대표 이미지가 늦게 뜨는 문제가 첫 화면 체감 속도를 떨어뜨렸습니다.

- 대표 이미지에는 `fetchPriority="high"`를 적용해 우선 로딩
- 나머지 이미지는 `lazy loading`으로 전환해 불필요한 초기 로딩 부담을 줄임
- 용량이 큰 PNG는 `sharp`로 WebP 변환
- **이미지 로딩 시간 약 30% 감소**, 첫 화면 노출 시점 단축

## 📜 스크롤 리렌더 제거

스크롤할 때마다 헤더 상태를 갱신하는 로직이 있었는데, 이 상태 갱신이 불필요한 리렌더를 계속 일으키고 있었습니다.

- 상태 대신 `useRef`와 `data attribute` 방식으로 헤더 표시를 전환
- 그 결과 **스크롤 중 React 렌더가 발생하지 않는** 구조로 개선

## 🔍 SPA SEO 대응 (prerender)

SPA 특성상 검색엔진 크롤러가 자바스크립트 렌더링 이후의 본문을 제대로 읽지 못하는 문제가 있었습니다.

- 메타데이터와 `hreflang`을 적용한 뒤 prerender(SSG) 처리
- 생성된 정적 HTML을 S3에 자동 업로드하는 파이프라인 구성
- 다국어 페이지까지 검색엔진 노출 문제를 함께 해결
