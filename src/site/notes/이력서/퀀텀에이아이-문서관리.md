# 📁 문서관리 시스템 — 보험금 청구 서류 자동화

🧭 **바로가기** — [[index\|🏠 홈]] · [[index\|🧑‍💻 이력서 홈]]

**소속**: 주식회사 퀀텀에이아이 (Quantum AI) · **기간**: 2022.11 ~ 2023.03 · **역할**: 프론트엔드 / 백엔드 개발

**Stack**: Spring Boot, JSP, jQuery, JavaScript, CKEditor4, MariaDB

---

## 개요

보험금 청구 서류 처리를 자동화하는 문서관리 시스템으로, 첫 직장에서 프론트엔드와 백엔드를 함께 경험한 프로젝트입니다.

## 🖥️ 백엔드 — CRUD API와 데이터 설계

- Spring Boot의 Controller-Service-Repository 구조로 문서 등록·조회·수정 CRUD API 구현
- 문서·사용자·청구 이력 테이블 설계
- 문서에서 추출·요약한 텍스트를 보험금 청구 입력값으로 연결해 MariaDB에 적재

## 🖋️ 프론트엔드 — 문서 작성 화면

- JSP·jQuery로 문서 작성 화면 구현
- CKEditor4를 연동해 서식 있는 문서 작성 기능 제공
