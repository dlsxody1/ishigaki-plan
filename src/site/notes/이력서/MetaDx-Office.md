# 🗂️ MetaDx Office — 사내 전자결재와 경비 관리

🧭 **바로가기** — [[index\|🏠 홈]] · [[index\|🧑‍💻 이력서 홈]]

**소속**: 주식회사 메타디엑스 (MetaDx Inc.) · **기간**: 2025.05 ~ 2026.07 · **역할**: 프론트엔드 개발

**Stack**: React 19, TypeScript, TanStack Router/Query, react-hook-form, zod, Vite, Vitest, steiger(FSD lint)

---

## 개요

사내에서 쓰는 전자결재·경비 관리 시스템입니다. 결재 로직은 한 번 오류가 나면 결재 건 전체에 영향을 주기 때문에, 기능 구현만큼이나 **검증과 안정성**에 신경 쓴 프로젝트였습니다.

## ✅ 입력값·제출 데이터 관리

- 전자결재·경비 관리 기능을 개발하면서 `react-hook-form`과 `zod`로 입력값과 제출 데이터의 타입·유효성을 관리
- 폼 상태와 검증 로직을 분산시키지 않고 한곳에서 관리해 결재 항목이 추가되어도 검증 규칙을 추적하기 쉽게 구성

## 🧪 단위 테스트와 CI

결재 상태머신, 401 인터셉터, 인증 가드, 결재선 금액 규칙, 제출 스키마 등은 오류가 나면 결재 건 전체에 영향을 주는 로직이라 판단했습니다.

- 이 영역에 **단위 테스트 25개**를 적용
- `tsc`·린트·빌드를 CI에 포함시켜 배포 전에 자동으로 검증되도록 구성

## 🏗️ 아키텍처 규칙 검사

- `steiger`로 FSD(Feature-Sliced Design) 레이어 간 의존성 규칙을 검사
- 레이어 경계를 넘는 의존이 생기면 빌드/검사 단계에서 걸러지도록 구성
