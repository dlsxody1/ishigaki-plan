# 🧬 CancerVET — 진단 리포트 자동 생성 파이프라인

🧭 **바로가기** — [[index\|🏠 홈]] · [[index\|🧑‍💻 이력서 홈]]

**소속**: 주식회사 메타디엑스 (MetaDx Inc.) · **기간**: 2025.01 ~ 2025.05 · **역할**: 프론트엔드 개발

**Stack**: Python, FastAPI, Playwright, HTML/CSS, AWS Lambda, S3

---

## 개요

검사 결과를 사람이 읽기 좋은 PDF 리포트로 자동 생성하는 파이프라인을 만든 프로젝트입니다. 프론트엔드 기술(HTML/CSS)을 문서 생성 파이프라인에 적용하고, 흩어져 있던 인프라 구조를 정리하는 작업까지 함께 했습니다.

## 📄 HTML → PDF 리포트 파이프라인

- 검사 결과 리포트 UI를 HTML/CSS로 제작
- Playwright로 해당 UI를 PDF로 변환하는 파이프라인 개발
- 웹 기술로 만든 화면을 그대로 문서 산출물로 재사용하는 방식을 택해 리포트 레이아웃 유지보수를 프론트엔드 작업 방식 그대로 가져감

## 🔤 한글 폰트 렌더링 문제 해결

- 로컬 환경과 Linux 컨테이너 환경의 한글 폰트가 서로 달라 PDF 출력 결과가 어긋나는 문제 발생
- Pretendard, NotoSansKR을 웹폰트로 직접 포함시켜 환경에 상관없이 동일한 결과가 나오도록 해결

## 🔧 인프라 구조 통합

- AWS Lambda와 S3로 분리되어 있던 구조를 FastAPI 서버로 통합하는 작업에 참여
