| `과제전형` | 사전 과제 / 코딩 테스트 진행 중 | 과제 요구사항 정리, 제출 후 회고 메모 |
| `1차면접` | 실무 면접 예정 또는 진행 중 | 기술 질문 + 도메인 질문 집중, 역질문 3개 준비 |
| `2차면접` | 임원 / 컬처핏 면접 단계 | [[면접준비/이직-공통질문\|이직-공통질문]] 위주, 이직 사유·커리어 방향 정리 |
| `최종합격` | 합격 통보 받음 | 처우 협의 메모, 입사일 조율 |
| `불합격` | 탈락 | 회고 한 줄 남기기 (어떤 질문에서 막혔는지) |
| `보류` | 내가 진행을 멈춘 상태 | 이유 메모 (스택 불일치, 처우, 우선순위 등) |
