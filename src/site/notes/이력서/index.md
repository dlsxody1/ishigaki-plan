## 👋 소개

2년 3개월 동안 동물병원 임상 SaaS, 사내 전자결재 시스템, 기업 홈페이지를 개발했습니다. 주로 React와 TypeScript를 사용했고, 필요할 때는 백엔드 API와 배포 환경까지 직접 다뤘습니다.

기능을 만드는 것뿐 아니라 실제 운영 과정에서 생기는 성능 문제와 유지보수 문제를 줄이는 데 관심이 많습니다. 최근에는 Claude Code와 MCP를 개발 과정에 활용하면서, AI가 만든 코드도 기존 프로젝트의 구조와 규칙을 지킬 수 있도록 개발 환경을 정리하고 있습니다.

> [!tip] 지금 관심 있는 주제
> AI 코드 생성이 늘어날수록 사람이 아니라 **도구가 구조를 지켜주는 장치**가 필요하다고 생각합니다. 커스텀 린트 훅, 서브에이전트 역할 분리, 공유 컨텍스트 레포지토리 같은 장치를 직접 만들고 팀에 적용하는 일을 좋아합니다.
